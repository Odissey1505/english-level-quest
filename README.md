# 📖 English Level Quest

Адаптивний тест на рівень англійської (CEFR A1–C1) у вигляді інтерактивної книжки: одне завдання на сторінці, справжнє перегортання сторінок, без вертикальної прокрутки. Три вікові треки зі своїм оформленням — **10–12** (з лисом Lex), **13–17** (стиль коміксу) і **дорослі** (спокійний «блокнот»). Наприкінці учень отримує «паспорт рівня», а вчитель — детальний звіт.

Без бібліотек, без збірки, без сервера. Нічого нікуди не надсилається — усе залишається в браузері.


## Як пройти тест

1. Обкладинка → ім'я + вікова група → «Open the book».
2. 8 розділів: ⚡ Quick Start · 🗝️ Word World · ⚗️ Grammar Lab · 💬 Real English · 📜 Read & Use · 🎧 Listen Up · 🎙️ Speak Up · 🐉 Level Boss.
3. 25 завдань з вибором відповіді + 2 усні відповіді, ≈15–20 хв.
4. Паспорт рівня: загальний рівень + окремо кожна навичка (а не «74 % → B1»).
5. Кнопка **📋 Teacher report** — звіт для вчителя.

Клавіатура: `1–4` або `A–D` — відповідь, `Enter` — перегорнути сторінку.

## Звіт для вчителя

- загальний рівень і рівень кожної навички, кількість завдань на кожну;
- **говоріння**: аудіозапис (можна прослухати й завантажити), автотранскрипт або письмова відповідь, рубрика 0–4 за 5 критеріями → підказка рівня → підтвердження вчителем (одразу перераховує загальний рівень);
- діагностика за поняттями: ✓ сильні / △ у процесі / ✕ потребує уваги — для кожної навички;
- усі відповіді: рівень, поняття, відповідь учня, правильна відповідь, час;
- 🖨 друк / збереження в PDF, ⬇ JSON, 📋 короткий підсумок у буфер.

> Звіт існує лише в цій вкладці. Збережіть PDF або JSON **до** закриття сторінки чи «New quest».

## Запуск

**Локально:** просто відкрийте `dist/english-level-quest.html` (або `index.html`) у браузері.
Для запису мікрофона браузер вимагає `https://` або `localhost`, тож для повного тесту з говорінням краще:

```bash
cd english-level-quest
python3 -m http.server 8000      # → http://localhost:8000
```

**GitHub Pages:**

1. Створіть репозиторій (або папку в наявному) і завантажте весь вміст `english-level-quest/`.
2. *Settings → Pages → Deploy from a branch → `main` / root* (або `/docs`, якщо кладете туди).
3. Через хвилину тест доступний за адресою `https://<user>.github.io/<repo>/`.

## Як працює оцінювання (коротко)

- **Quick Start** (A1 → A2 → B1) визначає стартову точку; кожен розділ починається на крок нижче й швидко піднімається, доки учень відповідає правильно.
- Після першої помилки рівень змінюється лише за кількома доказами (≥2 правильні — вгору, ≥2 неправильні — вниз). «Секретні діагностичні» завдання (since/for, *I've seen him yesterday*, інверсія тощо) мають більшу вагу.
- Кожна навичка оцінюється **окремо**; загальний рівень — зважене середнє всіх навичок, не лише граматики.
- Говоріння: друге питання поглиблює ту саму тему — простіше, стандартне або «stretch» залежно від першої відповіді. Автооцінка тут попередня (за обсягом), остаточну ставить учитель за рубрикою. Акцент не знижує оцінку.

Детально — у `docs/architecture.md`.

## Як додати завдання

1. Додайте об'єкт у `js/question-bank.js` (поля — див. `docs/architecture.md` §2). `correctAnswer` — індекс правильного варіанта; варіанти перемішуються автоматично під час тесту.
2. Перевірте банк: `node tools/validate-bank.js`
3. Якщо користуєтеся однофайловою версією: `node tools/build-standalone.js`

Найбільше нових завдань зараз потребують **Listen Up** і **Read & Use** (по 3 на рівень у кожній віковій групі) — це вплине на різноманітність тесту між учнями найсильніше.
