ENGLISH LEVEL QUEST

Assessment System, CEFR Logic & Question Bank

Build the assessment system and question bank for an interactive English placement test called English Level Quest.

The test is designed for three age categories:

- 10–12
- 13–17
- Adults

It estimates the learner's CEFR level:

- A1
- A2
- B1
- B2
- C1

The complete test should normally take approximately 15–20 minutes.

The test must NOT feel like a traditional exam.

The experience should combine:

- mini-games
- pictures
- conversations
- chats
- real-life situations
- audio
- sentence building
- interactive corrections
- short reading
- speaking challenges

The assessment must still be linguistically meaningful and useful to a teacher.

---

1. CORE ASSESSMENT PHILOSOPHY

Use this fundamental model:

AGE → CEFR → SKILL → TOPIC → QUESTION TYPE → QUESTION

Example:

13–17 → B1 → Grammar → Social Media → Second Conditional → Chat Completion

Another example:

Adult → A2 → Listening → Travel → Specific Information → Airport Announcement

Another:

10–12 → B2 → Speaking → School Rules → Opinion & Argument → Voice Response

Age determines the CONTEXT.

CEFR determines the LANGUAGE DIFFICULTY.

Skill determines WHAT ABILITY is being measured.

Question type determines HOW the learner interacts with the task.

Never confuse age with CEFR level.

A B1 11-year-old and a B1 35-year-old should demonstrate approximately B1 language ability, but they should not receive identical topics or situations.

4. QUESTION DESIGN PHILOSOPHY

Questions should gradually move from recognition to production.

Lower levels can use more:

- pictures
- matching
- simple choices
- concrete vocabulary

Higher levels should increasingly test:

- contextual meaning
- naturalness
- inference
- register
- nuance
- collocations
- implied meaning
- argumentation
- spontaneous production

Do not make B2/C1 simply “A2 questions with more difficult words.”

12. SECRET DIAGNOSTIC ITEMS

Include carefully selected questions that discriminate well between neighbouring levels.

Examples:

A2 → B1:

“I've lived here _____ 2022.”

since / for / from / during

B1:

“I've seen him yesterday.”

Ask learner to correct it.

B1 → B2:

“He suggested me to go home.”

Ask learner to make it natural.

Expected:

“He suggested going home.”

B2:

“Thanks for finally replying.”

Ask learner to identify likely implied tone from context.

C1:

Provide two grammatically correct sentences with different registers and ask which is more appropriate in a specific context.

These questions should receive greater diagnostic weight than extremely easy recognition questions.

---

13. ADAPTIVE QUESTION SELECTION

Do not ask all questions.

The question bank should contain many possible items.

A normal learner should receive approximately 20–30 scored interactions.

Start around A2/B1 unless initial information suggests otherwise.

Example:

B1 item → correct
→ another B1 diagnostic item

correct again
→ B2 probe

B2 correct
→ another B2 question

B2 incorrect
→ return to B1/B1+

The algorithm should seek the learner's highest stable performance level.

Do not move level after every single answer.

Require multiple pieces of evidence.

---

14. SKILL-SPECIFIC ADAPTATION

Track skills independently.

Example learner:

Vocabulary → B2
Grammar → B1
Reading → B2
Listening → B1
Speaking → A2+/B1

Do not force every section to the same difficulty.

If Vocabulary performance is strong, Vocabulary can probe B2 while Grammar remains around B1.

---

15. SPEAKING ADAPTATION

Speaking should dynamically deepen the same topic.

Example:

START:
“Tell me about your favourite hobby.”

Simple response:
→ “Why do you like it?”

Stronger response:
→ “How has your interest in it changed over time?”

Very strong response:
→ “Do hobbies need to be productive to be valuable?”

This creates an invisible:

A2 → B1 → B2/C1

speaking ladder.

18. SPEAKING EVALUATION

Do not evaluate speaking based solely on whether the learner makes mistakes.

Analyse:

- task completion
- comprehensibility
- fluency
- vocabulary range
- vocabulary appropriacy
- grammatical range
- grammatical accuracy
- coherence
- sentence complexity
- pronunciation/intelligibility

Accent must NOT lower the score simply because it is non-native.

---

19. SPEAKING CEFR INDICATORS

A1:
uses isolated words and basic sentences.

A2:
connects simple sentences about familiar topics.

B1:
can sustain a short response, explain reasons and describe experiences.

B2:
develops arguments, gives examples, uses varied structures and handles follow-up questions.

C1:
expresses complex ideas flexibly, precisely and coherently with nuanced vocabulary and sophisticated structures.

---

20. QUESTION QUALITY RULES

Every multiple-choice question must have:

- exactly one clearly correct answer
- plausible distractors
- no accidental second correct answer
- no grammar clue revealing the answer
- no absurd distractors

BAD:

“I _____ football yesterday.”

played
banana
beautiful
teacher

GOOD:

played
have played
play
was play

Distractors should reflect realistic learner errors.

---

21. DO NOT OVERTEST GRAMMAR TERMINOLOGY

Never ask:

“Which tense is this?”

unless explicitly needed.

Prefer:

“Which sentence fits the situation?”

The placement test measures ability to USE English, not ability to name grammar rules.

---

22. NATURAL ENGLISH PRINCIPLE

From B1 upward, include questions where multiple sentences may be understandable but only one is natural and contextually appropriate.

However, never mark a grammatically and pragmatically valid alternative as wrong merely because another answer sounds slightly better.

If more than one option is defensible, rewrite the item.

---

23. RESULTS

The final result should NOT simply be:

“You got 74%, therefore B1.”

Generate:

Overall CEFR estimate

and separate estimates for:

- Vocabulary

27. CRITICAL PRINCIPLE

The system must distinguish:

LANGUAGE DIFFICULTY

from

TOPIC DIFFICULTY.

A question does NOT become C1 merely because the topic is complicated.

For example:

“Is artificial intelligence good?”

is not automatically C1.

Conversely, sophisticated language can be tested using age-appropriate topics.

CEFR classification must depend on the linguistic demands placed on the learner:

- vocabulary
- grammatical complexity
- comprehension
- inference
- discourse
- fluency
- communicative function

---

28. FINAL GOAL

The learner should experience:

“I played several short English challenges and discovered my level.”

The teacher should receive:

“I now know approximately what this learner can do, which language systems are strong, where the gaps are, and what level to start teaching.”

The system should therefore balance:

FUN + SPEED + CEFR VALIDITY + DIAGNOSTIC VALUE.

Do not create a traditional school test disguised with colourful buttons.

Create a genuinely interactive adaptive language assessment.
